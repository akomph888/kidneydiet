📋 สรุปฟีเจอร์เด่นของโปรแกรมอาหารโรคไตอัจฉริยะ (KidneyDiet):
การคำนวณตามหลักอายุรศาสตร์โรคไต (Clinical Nephrology Calculator):

อ้างอิงน้ำหนักตัวในอุดมคติ (Ideal Body Weight - IBW): เป็นแนวทางมาตรฐานที่นักกำหนดอาหารใช้ เพราะผู้ป่วยโรคไตที่มีอาการบวมน้ำ (Edema) หรือผู้ป่วยน้ำหนักเกิน หากคำนวณจากน้ำหนักปัจจุบันจะได้ค่าโปรตีนที่คลาดเคลื่อนและเป็นอันตรายได้

คำนวณโปรตีนเข้มงวดตามระยะ: ไตระยะเริ่มต้นคุมเบาบาง 0.8 กรัม, ระยะ 3-5 คุมเข้มงวด 0.6 กรัม, และเพิ่มขึ้นเป็น 1.2 - 1.3 กรัมสำหรับผู้ที่ฟอก/ล้างไตแล้ว เพื่อป้องกันการสูญเสียกล้ามเนื้อจนขาดสารอาหาร

ระบบการติดตามและจดบันทึกน้ำดื่ม (Interactive Fluid Tracker):

ออกแบบระบบเพื่อป้องการ "น้ำท่วมปอด" และ "หัวใจล้มเหลว" โดยจำกัดน้ำดื่มของแต่วันตามระยะโรคที่เลือก พร้อมให้ผู้ป่วยหรือผู้ดูแลกดจดบันทึกได้ตลอดทั้งวัน

ตารางจำลองอาหารโรคไต 7 วันแบบพลวัต (Dynamic 7-Day Meal Planner):

สามารถดูเมนูแนะนำตั้งแต่วันจันทร์ถึงอาทิตย์ โดยแอปพลิเคชันจะปรับเปลี่ยนสัดส่วนของพลังงานและวัตถุดิบอัตโนมัติตามระดับความเสื่อมของโรคไตที่เลือก

คลังสูตรอาหารและคู่มือการคุมแร่ธาตุอย่างละเอียด (Renal Guide & Database):

สอนเคล็ดลับสำคัญ เช่น "การลวกต้มผักแล้วบีบน้ำออก" เพื่อสลัดโพแทสเซียมส่วนเกิน

เน้นย้ำ "แป้งปลอดโปรตีน" (วุ้นเส้น, สาคู) เพื่อรักษาน้ำหนักตัวไม่ให้ผอมซีด

คำเตือนความเสี่ยงวิกฤต เช่น มะเฟือง ซึ่งเป็นสารพิษร้ายแรงต่อเซลล์ประสาทของผู้ป่วยโรคไต
